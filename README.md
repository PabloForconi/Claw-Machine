# Claw Machine

**Jugar:** https://pabloforconi.github.io/Claw-Machine/

Prototipo de juego 3D para el navegador: una máquina de garra llena de cápsulas. Todo está en `index.html`, sin build; usa Three.js desde CDN, así que se abre directo en el navegador (con internet).

## Cómo se juega

- Empezás con 10 fichas; cada intento cuesta una.
- Mové la garra con la cruceta (o las flechas / WASD): izquierda-derecha y adelante-atrás. Bajala con **¡BAJAR!** (o Espacio). Tenés 15 segundos por intento.
- Guiate por la sombra de la garra para saber dónde va a caer.
- Si la garra agarra la cápsula bien centrada es más difícil que se le resbale.
- Cada cápsula que cae en el hueco de **PREMIOS** suma 1 punto; las doradas suman 5, pero se resbalan más.
