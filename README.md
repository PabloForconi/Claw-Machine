# Claw Machine

Prototipo de juego HTML: una máquina de garra llena de cápsulas. Todo está en `index.html`, sin dependencias ni build; se abre directo en el navegador.

## Cómo se juega

- Empezás con 10 fichas; cada intento cuesta una.
- Mové la garra con ◀ ▶ (o las flechas / A-D) y bajala con **¡BAJAR!** (o Espacio). Tenés 15 segundos por intento.
- Si la garra agarra la cápsula bien centrada es más difícil que se le resbale.
- Cada cápsula que cae en **PREMIOS** suma 1 punto; las doradas suman 5, pero se resbalan más.
